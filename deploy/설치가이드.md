# 생산스케줄링 서버 설치 가이드 (상시 가동 노트북)

> 안 쓰는 노트북 1대를 "생산스케줄링 서버"로 만들어 24시간 가동합니다.
> 내 PC를 꺼도 이 노트북이 켜져 있는 한 시스템이 돌아갑니다.
> 팀원은 브라우저로 `http://노트북IP:3000` 으로 접속합니다.

구조:
- 서버 실행/DB는 모두 **노트북 로컬 디스크(C:)** 에서 동작합니다.

---

## 준비물
- 안 쓰는 노트북 (Windows 10/11, 사양 낮아도 됨)
- 사내 네트워크(유선 권장) 연결
- 이 프로젝트 폴더 전체

---

## A. 노트북 기본 설정
1. **Node.js LTS 설치** — https://nodejs.org 에서 LTS 버전 다운로드 후 설치
   (설치 확인: 명령프롬프트에서 `node -v` 입력 시 버전이 보이면 OK)
2. **절전 끄기 (중요!)** — 설정 > 시스템 > 전원
   - "화면/절전: 안 함"
   - 노트북: "덮개를 닫을 때: 아무 것도 안 함"
   - (제어판 > 전원 옵션 > 고급 설정에서 최대절전/하이브리드 절전도 끄기)

## B. 프로젝트 복사
- 이 프로젝트 폴더를 노트북의 예: `C:\production-scheduler` 로 복사
- (큰 폴더면 `node_modules`, `.next`, `data` 폴더는 빼고 복사해도 됩니다 — 아래 설치 단계에서 다시 생성됨.
  단, 기존 데이터를 옮기려면 `data\production.db` 는 꼭 같이 복사)

## C. 최초 설치 + 빌드 (1회)
- `deploy\1-install-build.bat` 더블클릭 → 자동으로 설치·빌드 진행
- "완료!" 메시지가 나오면 성공

## D. 서버 시작 + 접속 확인
1. `deploy\2-start-server.bat` 더블클릭 → 서버 시작 (창은 켜둔 채로 둠)
2. 노트북 IP 확인: 명령프롬프트에서 `ipconfig` → "IPv4 주소" (예: `10.3.50.x`)
3. **방화벽 열기** (관리자 권한 PowerShell에서 한 번만):
   ```powershell
   New-NetFirewallRule -DisplayName "ProductionScheduler 3000" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
   ```
4. 다른 PC 브라우저에서 `http://노트북IP:3000` 접속 확인

## E. 전원 켜지면 자동 시작 (정전 후에도 복구)
1. **자동 로그인 설정** — 실행(Win+R)에 `netplwiz` → 계정 선택 → "사용자 이름과 암호를 입력해야…" 체크 해제 → 비번 입력
2. **시작 시 서버 자동 실행** — 작업 스케줄러:
   - 작업 만들기 → 트리거: "로그온할 때"
   - 동작: 프로그램 시작 → `C:\production-scheduler\deploy\2-start-server.bat`
3. **정전 대비** — 노트북은 배터리가 UPS 역할. 추가로 BIOS에서 "AC 전원 복구 시 자동 부팅(Restore on AC Power)" 옵션이 있으면 켜기

## F. 고정 IP (권장)
- 팀원이 항상 같은 주소로 접속하도록 노트북에 고정 IP 부여
- IT팀에 요청하거나, 공유기 DHCP 예약 설정 (불가하면 IP 바뀔 때 주소 다시 공지)

## G. 자동 배포 설정 (작업용 PC에서 수정 → 노트북 자동 반영) [방법 C]
> 이 설정을 하면, 작업용 PC에서 `배포.bat` 한 번 누르면 노트북이 약 10초 내 자동으로
> 새 코드를 빌드하고 재시작합니다. (라이브 데이터 `data\production.db` 는 절대 건드리지 않음)

**1) 노트북: 프로젝트 폴더 공유**
- `C:\production-scheduler` 폴더 우클릭 → 속성 → 공유 → 고급 공유 → "이 폴더 공유" 체크
- 권한 → 작업용 PC 사용자(또는 Everyone)에게 **"변경/쓰기" 허용**
- 공유 이름 확인 (예: `production-scheduler`)
- 노트북 컴퓨터 이름 확인: `cmd` 에서 `hostname` → 예: `PRODUCTION-PC`

**2) 노트북: 배포 감시 프로그램 자동 실행**
- (1회) 관리자 PowerShell: `Set-ExecutionPolicy -Scope LocalMachine RemoteSigned`
- 작업 스케줄러 → 새 작업 → 트리거 "로그온할 때"
  - 동작: 프로그램 `powershell.exe`
  - 인수: `-File "C:\production-scheduler\deploy\watch-deploy.ps1"`
- (서버 자동시작 작업 E와 함께, 이 감시 작업도 같이 등록)

**3) 작업용 PC: `배포.bat` 경로 한 번 수정**
- `deploy\배포.bat` 을 메모장으로 열어 맨 위
  `set "LAPTOP=\\노트북컴퓨터이름\production-scheduler"`
  의 `노트북컴퓨터이름` 을 1)에서 확인한 이름(예: `PRODUCTION-PC`)으로 바꿔 저장

**평소 사용법**
- 작업용 PC에서 코드 수정 후 → `deploy\배포.bat` 더블클릭 → 끝.
- 노트북이 알아서 빌드+재시작하고, 진행상황은 노트북의 감시 창에 표시됩니다.

---

## 평소 운영
- **노트북은 항상 켜두고, 덮개 닫아도 꺼지지 않게** 설정 (D~E 참고)
- 서버 창을 실수로 닫아도 자동 재시작됨. 노트북 재부팅 시에도 자동 시작됨
- 접속 주소: `http://노트북IP:3000`
- 데이터는 `C:\production-scheduler\data\production.db` 한 파일에 저장됩니다. (필요 시 이 파일을 USB 등으로 따로 복사해 두면 백업이 됩니다)
