# 외부 접속 설정 가이드 (Tailscale Funnel — 고정 주소)

사내망(`http://10.3.50.72:3000`)뿐 아니라 **외부(집·외근·휴대폰 LTE)에서도** 스케줄러에 접속하게 합니다. 주소가 **영구 고정**(재부팅해도 안 바뀜)이고, **노트북에만** Tailscale을 설치하면 됩니다. 보는 사람은 **브라우저만** 있으면 됩니다(앱 설치 불필요).

## 왜 이 방식인가
- 노트북 서버는 **회사망 NAT 뒤(공유 공인 IP)**라 외부에서 직접 들어올 수 없습니다. 회사 공유기 포트포워딩은 보통 권한이 없어 불가합니다.
- **Tailscale Funnel**은 노트북이 **바깥으로 나가는 연결만** 쓰므로 공유기 설정이 필요 없고, 노드(노트북)마다 **고정된 `https://<이름>.<테일넷>.ts.net` 주소**를 줍니다 → 한 번 공유하면 끝.

---

## 설치 (노트북에서, 최초 1회)

### 1) Tailscale 설치 + 로그인
1. 노트북에서 https://tailscale.com/download/windows 에서 받아 설치.
2. 트레이의 Tailscale 아이콘 → 로그인(구글 계정 등). 또는 cmd에서:
   ```cmd
   "C:\Program Files\Tailscale\tailscale.exe" up
   ```
   → 브라우저가 열리면 로그인. 이때 만들어지는 **테일넷 이름**(`tailXXXXXX.ts.net`)이 주소에 들어갑니다.

### 2) Funnel에 필요한 기능 켜기 (Tailscale 관리자 콘솔, 1회)
https://login.tailscale.com/admin 에서:
- **DNS** → **MagicDNS** 켜기, **HTTPS Certificates** 켜기.
- **Access Controls(ACL)** → Funnel 권한 부여. (아래 `tailscale funnel 3000`을 처음 실행하면 콘솔에서 켜라는 안내 링크가 함께 뜹니다. 그 링크로 켜면 됩니다.)

### 3) Funnel 켜기 + 자동시작/주소표시 등록
배포로 `deploy\funnel.ps1`이 노트북 `C:\production-scheduler\deploy\`에 들어온 뒤, cmd에서:
```cmd
"C:\Program Files\Tailscale\tailscale.exe" funnel --bg 3000
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ps-funnel /t REG_SZ /d "powershell -NoProfile -ExecutionPolicy Bypass -File C:\production-scheduler\deploy\funnel.ps1" /f
powershell -NoProfile -ExecutionPolicy Bypass -File C:\production-scheduler\deploy\funnel.ps1
```
- 1줄: 포트 3000을 Funnel로 공개(백그라운드, 영구 유지). Tailscale 서비스가 **재부팅해도 자동 유지**합니다.
- 2줄: 부팅 때마다 `funnel.ps1`을 돌려 Funnel을 재확인하고 현재 주소를 앱에 표시되게 등록.
- 3줄: 지금 바로 1회 실행 → 고정 주소를 `tunnel-url.txt`에 기록.

### 4) 주소 확인
- 셋째 줄 실행 결과에 `PUBLIC URL = https://<이름>.<테일넷>.ts.net` 으로 표시됩니다.
- 또는 사내에서 `http://10.3.50.72:3000` 접속 시 상단 우측 **`🌐 외부 접속 주소`** 버튼(클릭=복사). 주소만 보려면 `http://10.3.50.72:3000/api/tunnel`.
- 이 주소를 한 번 공유/북마크하면, **이후 바뀌지 않습니다.** 외부 어디서나 브라우저로 접속됩니다.

직접 주소를 보려면 언제든:
```cmd
"C:\Program Files\Tailscale\tailscale.exe" funnel status
```

## ⚠️ 보안 (꼭 읽어주세요)
- 이 앱은 **로그인이 없습니다.** Funnel은 **공개**이므로 **주소를 아는 사람은 누구나** 스케줄을 보고 수정·삭제할 수 있습니다. 주소(`tailXXXXXX.ts.net`)는 추측이 쉽지 않지만 비밀은 아니니, 사외로 함부로 공유하지 마세요.
- 더 강하게 막고 싶다면 두 가지 선택지가 있습니다.
  1. **완전 비공개로 전환** — `funnel`(공개) 대신 `serve`(사내망 전용)로 바꾸면 **Tailscale에 로그인한 우리 기기만** 접속됩니다(공개 노출 0). 대신 접속하는 기기마다 Tailscale 앱 설치가 필요합니다.
     ```cmd
     "C:\Program Files\Tailscale\tailscale.exe" funnel --bg off
     "C:\Program Files\Tailscale\tailscale.exe" serve --bg 3000
     ```
  2. **앱에 간단한 로그인(비밀번호) 추가** — 원하시면 미들웨어로 공용 비밀번호 한 줄짜리 보호를 넣어드릴 수 있습니다. 알려주세요.

## 운영/배포 메모
- `tunnel-url.txt`는 **프로젝트 루트**(`C:\production-scheduler\`)에 생깁니다. `deploy\`가 아닌 이유: 자동 배포(`auto-update.ps1`)가 `deploy\`를 `robocopy /MIR`로 미러링해 git에 없는 파일을 매번 지우기 때문입니다. 루트는 동기화 대상이 아니라 안전합니다(이 파일은 `.gitignore` 처리됨).
- 배포로 서버가 잠깐 재시작되는 동안에도 **Funnel은 계속 살아 있습니다**(포트 3000만 중계). 서버가 내려간 몇 초간 502가 잠깐 보일 수 있습니다.
- 끄기: `"C:\Program Files\Tailscale\tailscale.exe" funnel --bg off` 후 Run 키 삭제 `reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ps-funnel /f`.
- 주소가 들어간 테일넷 이름을 바꾸고 싶으면 관리자 콘솔에서 머신 이름/테일넷 이름을 변경할 수 있습니다(그러면 주소도 그만큼 바뀌니 1회성으로만).
